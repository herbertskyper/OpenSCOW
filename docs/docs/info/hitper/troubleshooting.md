# 常见问题

## 开通“我的超算账户”后，资源在哪里？

账户开户准备权限、额度和目录，不分配运行中的 CPU 或 GPU。通过 Slurm 提交作业后，由调度器分配集群资源；申请云工作空间后，由独立工作空间资源池分配资源。两种流程和数据目录不同。

## 为什么不能直接 SSH 登录集群节点？

当前部署关闭了普通用户的节点直接 SSH、登录节点网页 Shell 和登录桌面。请通过网页文件管理准备数据，再提交 Slurm 作业；需要 SSH 开发时申请独立工作空间。保存工作空间公钥不会开放集群节点登录。

## 为什么 GPU 只能选 0，或者创建按钮不可用？

先检查模板：Ubuntu 虚拟机和 Alpine 不支持 GPU。PyTorch 和 Ubuntu / CUDA 容器支持 GPU，但个人额度用完、GPU runtime 未准备好或镜像未就绪时，对应选项或按钮会被禁用。

即使个人额度足够，提交时仍可能因全局容量、GPU 已被占用或主机可用内存 / 磁盘不足被拒绝。单用户当前默认最多 1 张 GPU，界面中的 2 卡选项不会因此自动开放。

## 申请了 GPU，但 PyTorch 看不到 CUDA 怎么办？

确认连接的是刚申请的 GPU 实例，且 GPU 数量不是 0。先执行 `nvidia-smi -L`；再确认使用 PyTorch 模板和正确的 Python 环境。通用 CUDA 镜像并不保证安装了 PyTorch，自己创建的不继承系统包的虚拟环境也可能没有该包。

如果设备可见但框架报驱动、CUDA 或内核兼容错误，向管理员提供实例编号、镜像、`nvidia-smi` 和完整报错。GPU 被分配并不代表任意版本框架或模型都与该硬件兼容。

## SSH 连接被拒绝或超时

确认实例显示“运行中”，复制最新卡片中的主机和端口，而不是使用网页的 HTTP 端口或集群登录节点地址。网页访问和工作空间 SSH 使用不同端口，所在网络可能需要额外放行。

如管理员已提供部署机的 SSH 跳转别名，可建立本地转发。例如本机确实已有 `scow` 别名、实例端口为 22000 时：

```sh
ssh -N -L 22000:127.0.0.1:22000 scow
```

保持隧道窗口打开，在另一终端使用页面完整命令，把主机改为 `127.0.0.1`，端口对应本地转发端口，并保留实例的 `HostKeyAlias`。该方式需要管理员授权部署机跳转访问，普通平台账号不自动获得此权限。

## SSH 提示 Permission denied (publickey)

使用申请时公钥对应的私钥，必要时加入 `-i 私钥路径 -o IdentitiesOnly=yes`；登录用户使用页面给出的 `hitper`。不要把 `.pub` 文件当成私钥。保存新公钥不会自动修改已有实例的登录密钥，复用虚拟机磁盘时尤其需要原公钥。

## SSH 提示主机密钥变化

保留页面命令里的 `HostKeyAlias=hitper-实例编号`，用于区分端口复用后的新实例。若同一个实例编号突然出现密钥变化，应先请管理员确认是否重建或恢复了环境；不要通过关闭主机密钥校验来掩盖问题。

## 停止了实例，为什么还是没有额度？

停止仍保留 CPU、GPU、内存和实例数额度，且不暂停期限。需要归还计算资源时使用“释放”，并等待操作成功。数据卷继续占用磁盘额度，需在确认不再需要数据后单独永久删除。

## 实例已经释放，文件还在吗？

Docker 仅保留 `/home/hitper`，虚拟机保留整个系统盘，保留的卷显示在“我的持久数据”中。临时目录或容器系统层不能按持久数据恢复。永久删除数据卷后，平台没有提供撤销或自动快照恢复。

## 为什么工作空间文件在门户文件管理中看不到？

门户文件管理访问集群个人目录，工作空间使用独立持久盘，二者不会自动同步。可通过本机 SFTP / SCP 与网页上传下载中转文件，不要假设 Slurm 作业能直接读取工作空间目录。

## 为什么不能在 Docker 中 sudo 或 apt install？

Docker 工作空间提供非 root 用户和只读系统层。可在个人目录使用 Python 虚拟环境；需要系统级安装时选择 Ubuntu 虚拟机，或由管理员维护新的受控镜像。平台不提供用户特权容器或宿主机 Docker 管理权限。

## 计算开户或文件管理一直失败

先在云工作空间页查看开户步骤，失败时重试，并记录用户名、时间和诊断编号。文件管理应使用页面的重连与开户状态入口。管理员可检查扩展服务、门户日志、LDAP、目录权限和受控 SSH 服务访问；不要给普通用户重新开放节点 SSH 来绕过故障。

## 管理系统没有工作空间申请入口

这是当前设计：管理系统用于资源、账户和记录管理，申请工作空间请回门户。全局资源页需要平台管理员角色，普通用户访问得到 403 属于正常权限限制。

## 工作空间是否扣费？

目前工作空间不从 Slurm 账户余额扣费，用量页面是 CPU、内存和实例时长的采样估算。Slurm 作业仍采用原平台计费与冻结策略。工作空间还没有独立账单，不要把平台体验余额当成已实现的工作空间计费余额。
