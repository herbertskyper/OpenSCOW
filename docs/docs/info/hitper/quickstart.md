# 快速上手

## 1. 注册并登录

打开管理员提供的平台地址，在登录页进入注册入口，填写用户名、姓名、邮箱和密码。用户名使用 3–20 位小写字母、数字或下划线，且以字母开头；密码应符合页面规则。已有平台或 LDAP 同名账号不能重复注册。

注册成功后即可登录，不需要等待人工审核。平台同时在后台准备计算账户，网页登录成功不代表计算开户已经完成。新注册用户为普通用户，不具备管理员权限。

## 2. 查看计算开户状态

进入“交互式工作空间 → 云工作空间”，查看“我的超算账户”。系统依次准备计算账户、资源额度、初始体验额度、个人目录，并验证计算与平台服务访问权限。

- 显示“计算账户已就绪”后，可提交 Slurm 作业。
- 显示“排队中”或“正在准备”时，等待页面刷新。
- 显示失败时，按页面提示重试；仍失败时向管理员提供用户名和失败步骤。
- 已有用户尚未开通时，可点击“开通计算资源”。

计算账户通常命名为 `hp_用户名`。开通账户不会创建可直接使用的计算实例，也不会开放用户对集群节点的 SSH 登录。

## 3. 准备 SSH 公钥

在自己的电脑生成密钥；如果已有合适的密钥，可以直接使用现有公钥：

```sh
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_hitper -C hitper-workspace
cat ~/.ssh/id_ed25519_hitper.pub
```

将 `.pub` 文件的整行内容保存到页面“工作空间 SSH 公钥”，或在创建时粘贴。私钥保留在本机，不要上传到平台。每人最多保存 10 个公钥，页面显示公钥名称与指纹。

## 4. 申请第一个工作空间

1. 在顶部选择 PyTorch、Ubuntu 虚拟机或 Docker 镜像卡片。
2. 填写实例名：1–32 位字母、数字、下划线或连字符。
3. 根据任务选择 CPU、GPU、Memory。仅做一般开发时可选择 2 核 CPU、0 张 GPU、4 GiB 内存；需要 GPU 时选择支持 GPU 的容器模板。
4. 选择使用时长和持久数据卷，首次使用选择“新建独立数据卷”。
5. 选择已保存公钥或粘贴公钥，核对资源摘要和预计到期时间。
6. 点击“确认创建”，等待实例显示“运行中”。Docker 通常较快，虚拟机首次启动可能需要数分钟。

Ubuntu 虚拟机和 Alpine 模板不能申请 GPU。资源选项受个人剩余额度限制；镜像尚未准备好时不能创建该模板。

## 5. 连接并保存文件

复制实例卡片中的完整 SSH 命令。若使用上面单独创建的密钥，在命令中加入 `-i ~/.ssh/id_ed25519_hitper`：

```sh
# 地址、端口与 HostKeyAlias 均替换为实例页面提供的实际值
ssh -i ~/.ssh/id_ed25519_hitper \
  -o HostKeyAlias=hitper-实例编号 \
  -p 实例端口 hitper@工作空间主机
```

首次连接前核实目标地址。保留命令里的 `HostKeyAlias`，用于区分不同实例的 SSH 主机密钥。连接的是申请的工作空间，不是集群登录节点。

Docker 文件请保存到 `/home/hitper`；虚拟机的整个系统盘会保留。Slurm 作业所需文件通过门户文件管理准备，它们不会自动出现在工作空间中。

## 6. 使用结束后释放

“停止”便于后续继续使用，但仍占用计算额度，期限也继续计时。无需继续占用资源时，点击“释放”。计算资源回收成功后，数据卷留在“我的持久数据”中，可供重新申请时挂载。

不再需要数据时，先释放绑定的实例，再输入数据卷编号确认永久删除。更多规则见[工作空间使用](./workspaces.md)；连接失败时见[常见问题](./troubleshooting.md)。
